# Rutina Gera — app de entrenamiento

App móvil (PWA) de hipertrofia (foco glúteo / femoral / aductor) + mejora de VO2max, basada en el *Programa de entrenamiento — Versión 3*. Incluye el programa de 4 días y la variante de 3 días (Anexo A). Funciona sin conexión y guarda los datos en el propio teléfono.

## Instalar en el móvil
Abre el enlace de GitHub Pages del repositorio en el móvil:
- **Android (Chrome):** menú ⋮ → «Instalar aplicación».
- **iPhone (Safari):** Compartir → «Añadir a pantalla de inicio».

## Probar en el ordenador
```
python -m http.server 8765
```
desde esta carpeta, y abre http://localhost:8765

## Datos
Todo se guarda en el dispositivo (las fotos también). Usa **Perfil → Exportar datos** de vez en cuando para tener una copia de seguridad (las fotos no van en la copia).

> Guía educativa de entrenamiento general. No reemplaza la evaluación de un médico, nutricionista o entrenador certificado.
